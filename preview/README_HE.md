# תצוגת קונספט אינטראקטיבית

פתחו את `index.html` בלחיצה כפולה בדפדפן. אין צורך באינטרנט או בהתקנות.

זהו **אב־טיפוס ויזואלי עצמאי** להמחשת הקונספט בלבד, ולא פרויקט Next.js או חנות מוכנה לפרסום מסחרי. שלוש הקופסאות נפתחות בלחיצה, הסימון מתעדכן, ויש התאמה למסכים קטנים. התכשיטים הם איורי SVG מקוריים סכמטיים — לא תמונות מוצר אמיתיות או מודלי תלת־ממד.

Claude Code צריך לבנות את אתר ה־Next.js האמיתי על פי שאר קובצי החבילה ולא להסתפק בהעתקת ה־HTML הזה. ניתן להשתמש בו כהשראה לשפה הוויזואלית, למיקום הקופסאות ולזרימת החוויה.
